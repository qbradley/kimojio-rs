HTTP/1 observability qualification

Core, wrapper, and HTTP/1+HTTP/2 composite tests and doctests:
  No observation features: 506 passed, 0 failed, 0 ignored.
  Metrics only:            520 passed, 0 failed, 0 ignored.
  Diagnostics only:        513 passed, 0 failed, 0 ignored.

All features, also including the WebSocket FSM:
                           588 passed, 0 failed, 0 ignored.

The observation tests cover accepted and rejected completions, partial body
consumption, repeated offers, uncertain write progress, saturation, stale
deadlines, cancellation joins, and read-only snapshots.
Diagnostic tests cover request/response callbacks, informational responses,
readiness, trailers, body returns, closure, primary failures, and coalesced
API calls. Composition tests cover prefetched-input replay and child selection.

Wrapper tests exercise native and generic transports, exact byte counters,
live and final snapshots, idle wakeup, cancellation, queued and blocked queries,
startup failure, unpolled driver drop, duplicate binding, and real log delivery.
The tests preserve old snapshots and correlate logs with completed exchanges.
No observation tests remain ignored.
