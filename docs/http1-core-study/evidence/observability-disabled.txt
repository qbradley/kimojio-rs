All three builds disable metrics. "Baseline logs" enables the old diagnostics
feature. The simplified implementation has no diagnostics feature.
The common probe uses the default no-op log callback.
All client/server fixed/chunked roundtrips passed.

The simplified implementation and logging-enabled baseline have identical
emitted connection-symbol addresses and sizes. All 12 emitted Core functions
have identical instruction sequences after normalization of compiler-generated
symbol disambiguators and labels. Empty counter-helper calls add no code in
this optimized probe. The whole assembly differs in unrelated function order
and source metadata, so this is not a byte-identical executable claim.

The once-only primary-failure delivery flag remains in connection state.
Its retention explains the 8-byte layout increase over the fully disabled
baseline. Default callback elimination does not eliminate all bookkeeping.
The wrapper also retains a runtime check for its optional observation handle.
This probe does not measure wrapper throughput or an installed logger.
